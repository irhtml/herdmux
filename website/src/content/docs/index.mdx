## Features

<CardGrid>
  <Card title="One sidebar, every pane" icon="list-format">
    Tracks Claude Code, Codex, and OpenCode panes across every tmux session and window at
    once, so context switching stops meaning window switching.
  </Card>
  <Card title="Live status, prompts, responses" icon="comment-alt">
    Prompts, tool calls, response previews, background shell state, wait reasons,
    task progress, and subagent trees — all refreshing as the agents work.
  </Card>
  <Card title="Worktree-aware" icon="seti:folder">
    Spawn a fresh worktree + agent in a split of the current window, and tear it down —
    pane, worktree, and branch — in a single keystroke.
  </Card>
  <Card title="Desktop notifications" icon="signal">
    Native notifications when an agent finishes, needs a permission, or
    errors out. Configurable per event.
  </Card>
  <Card title="Agents driving agents" icon="puzzle">
    One agent can start, prompt, wait on, and read the replies of the others with
    `herdmux agent`. A bundled skill teaches Claude Code the rules.
  </Card>
  <Card title="Resume after reboot" icon="laptop">
    With tmux-resurrect, restored panes relaunch their agents with the conversation
    resumed, flags and config directories included.
  </Card>
</CardGrid>

## Quick start

Using [TPM](https://github.com/tmux-plugins/tpm):

```bash
set -g @plugin 'irhtml/herdmux'
```

Reload with `tmux source ~/.tmux.conf`, press `prefix + I` to install, and the
install wizard downloads a pre-built binary or builds from source.

Next, wire up your agent hooks — [Claude Code](/herdmux/getting-started/claude-code/)
installs as a plugin, [Codex](/herdmux/getting-started/codex/) is a
one-paste setup inside its own pane, and [OpenCode](/herdmux/getting-started/opencode/)
uses the bundled plugin bridge.

## Origins

herdmux started as a fork of [hiroppy/tmux-agent-sidebar](https://github.com/hiroppy/tmux-agent-sidebar)
and is developed independently.
